# что сделано и что открыто на эту дату

## Сделано

Версии 0.9.1–0.12.3 вышли за сессию `ed70b5f5` (2026-10-14 … 2026-11-03).
Что входит в каждую, — в `CHANGELOG.md`; последняя версия и согласованность
копий — `./release.sh check` (хороший результат: `everything agrees on X.Y.Z`).

- **Правило и guard.** Раздел «Найдено попутно» группирует пункты по проектам;
  пункты без id или готовый ответ с id другой сессии — guard один раз
  продолжает ход и просит перепечатать раздел с id (0.9.3, 0.10.9); отрицание
  («отдельной задачи нет») не считается откладыванием (0.10.6).
- **Терминальный режим.** `findings sessions`, `findings brief`, `findings fix`
  в терминале, `findings list --long`, решения по фильтру
  (`findings skip --session ID`), `findings PATH` / `--scope PATH`, поиск
  проекта вверх по дереву вне git.
- **Удобство.** Автодополнение bash (`bin/findings-completion.bash`), короткий
  `findings -h` и разделы `findings help COMMAND`, цвета только в терминале.

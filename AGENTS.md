# findings

Инструмент findings: правило «Найдено попутно», журнал находок, хуки для Claude Code, Codex и opencode, CLI для терминала. Как пользоваться — `README.md`, что в каждой версии — `CHANGELOG.md`.

## Commands

```bash
for t in tests/*.sh; do bash "$t" -q | tail -1; done   # три строки, failed 0 в каждой
shellcheck bin/findings-completion.bash                 # пусто
./release.sh check                                      # everything agrees on …
kb check                                                # notes agree
```

## A task is done when

Все три набора тестов дают `failed 0`, `./release.sh check` пишет
`everything agrees on` текущей версии (то есть закоммичено, есть тег, установленные
копии совпадают), и вывод этих команд приложен к ответу. Выпуск — через скилл
`release` (`/release`), а не голыми `./release.sh tag` и `git push`.
